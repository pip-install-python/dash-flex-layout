# Documentation site requirements  (`python run.py`)

# The flexlayout-dash PACKAGE itself needs only `dash>=4.1` and
# `typing_extensions` — see pyproject.toml. A `pip install flexlayout-dash`
# user needs nothing on this list; everything here exists to run the docs site
# and its live examples.
#
#     pip install -r requirements.txt
#
# To REBUILD the component (webpack bundle + regenerated Python wrappers) you
# additionally need `pip install "dash[dev]"`, which supplies
# dash-generate-components. That is a build tool, not a runtime dependency of
# either the site or the package, so it is deliberately not pinned here.
#
# Compatibility testing: CI installs this file with the pinned Dash line
# stripped, then installs one specific Dash version per job. The pin therefore
# has to stay on a single line tagged `# COMPAT-MATRIX: dash`.
# ---------------------------------------------------------------------------

# Core Dash 4.x + Mantine UI

# Markdown-driven docs engine (directives: toc / exec / source / kwargs).
# markdown2dash itself is NOT LISTED HERE ON PURPOSE — network standard, same

#
#     pip install -r requirements.txt
#     pip install --no-deps markdown2dash==0.1.2
#
# Skipping the graph means naming its REAL runtime deps here instead: dash,
# dash-iconify and dash-mantine-components are pinned above; mistune (the

# developer venv that once installed markdown2dash normally hides the gap.

# checks assert the dodge kept working (gunicorn >= 23 AND markdown2dash
# importable).
docutils!=0.21
jsonpath

pydantic>=2.3.0

# AI/LLM + SEO surfaces: /llms.txt, /<page>/llms.txt, /robots.txt, /sitemap.xml
#
# The >=2.3.3 floor is load-bearing, not cosmetic:
#   2.2.0  merge (not assign) semantics for page metadata, so the home-page
#          stub stopped overwriting registered llms_doc entries
#   2.3.2  fixes the OAI-SearchBot `Disallow` bug that 2.0-era sites papered
#          over with hand-written robots custom_rules (this repo never had
#          that workaround — verified, nothing to remove)
#   2.3.3  correct Anthropic robots taxonomy (ClaudeBot blocked as a training
#          crawler, Claude-User/Claude-SearchBot allowed), no directive
#          leakage into agent markdown, and the universal prerender that now
#          owns canonical/og/title — which is why templates/index.html no
#          longer hand-rolls those tags.
#   2.3.4  network standard (2plot.ai, 2plot.dev, boilerplate all run it):
#          resolve_site_title() gives every surface — /llms.txt H1, the llms
#          viewer chip, prerender titles — one place to agree on the brand.
#   2.4.0  tiered corpus documents: /llms-small.txt (compact briefing) and
#          /llms-full.txt (every page's prose in one fetch), the knobs
#          run.py registers with lib/page_tiers for the 402 experiment.
#   2.5.1  Tier-B SEO standard: configure_seo, crawler <title> carrying the
#          site name, per-page title/image_url/schema_type reaching the
#          crawler document, /favicon.ico answered with a redirect instead
#          of the app shell, and a prerender that no longer clobbers the
#          browser's per-page <title>.
#   2.6.0  truthful sitemaps: `lastmod=` on register_page_metadata is finally
#          EMITTED rather than swallowed into **kwargs and ignored, so the
#          dates docs/*/*.md declare are the dates crawlers see. Below this
#          every <lastmod> reverts to an invented build date. Also: icon
#          autodiscovery, and JSON-LD publisher `logo`.
#   2.6.1  the VISIBLE prerender. 2.6.0 shipped the prerender block with a
#          literal `hidden` attribute, so every visibility-respecting
#          consumer (HTML-to-text extractors, plausibly crawler content
#          weighting) read "Loading..." where the page's prose should be —
#          the outside-audit finding of 2026-08-22, and what THIS HOST was
#          serving that morning. run.py enforces this floor at boot and
#          tests/test_pages.py pins the visible shape.
dash-improve-my-llms[flask]>=2.6.1

# Clerk satellite auth — the interactive sign-in gate (lib/auth.py)
# ---------------------------------------------------------------------------
# VENDORED, not fetched: dash-clerk-auth is not on PyPI, so the release tarball
# is committed under vendor/ and installed from the working tree. Network
# floor is 1.0.5 (sha256 a2f9062e15a69fc79deeaf76fcf1380907a961978db558b2aa227572cb2b74f3),
# the release that adds the return-trip stale-gate reconciliation and the
# shared no-loop marker; 1.0.2's Sign Out never revoked the server session, so
# the signed __dca_identity cookie kept serving gated pages for up to 7 days.
#
# THE DOCKERFILE MUST `COPY vendor/` BEFORE THIS FILE'S INSTALL LAYER. If it
# doesn't, pip reports the missing path as a SOFT WARNING and then dies
# seconds later on an OSError that reads like a registry outage — a fork lost
# an afternoon to exactly that.
#
# LOAD-BEARING even when Clerk is switched off: dash-clerk-auth registers a
# Dash *entry-point hook*, so `Dash(...)` imports it during construction
# whether or not this app's code ever does. With clerk-backend-api missing,
# that import raises and the whole site fails to boot before any of lib/auth's
# guards can degrade gracefully — measured 2026-08-22 while porting this
# stack. So the two floors below are not optional extras; they are what makes
# the vendored package importable at all.
./vendor/dash_clerk_auth-1.0.5.tar.gz

clerk-backend-api>=7.0.0,<8
